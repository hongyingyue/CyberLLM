# CyberLLM

Cybersecurity-focused Large Language Models.
- Stage0: Data Generation
- Stage1: Continue pretrain
- Stage2: Instruction tuning by deepspeed
- Stage3: Reinforcement learning reasoning by verl


## Model
We use the training data based on [primus](https://arxiv.org/abs/2502.11191)

eval data based on [cti-bench](https://github.com/xashru/cti-bench) and [sec-eval](https://github.com/XuanwuAI/SecEval)
